## 🔎 Focus

<pre>
<code>$ cat focus.txt
Working at the intersection of offensive and defensive security: threat
modeling, secure CI/CD pipelines, intrusion detection, and application
security. I like proving security concepts in real, reproducible labs,
not just in theory.</code>
</pre>

- 🛡️ **AppSec** — SAST/DAST, secret scanning, security gates in CI/CD pipelines
- ☁️ **CloudSec** — isolated infrastructure, hardening, security observability
- 🕵️ **Blue Team / Detection** — honeypots, IDS, log and threat correlation
- 📐 **Threat Modeling** — STRIDE applied to real architectures
